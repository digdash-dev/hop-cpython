= CPython Script Executor
:imagesdir: ../src/main/resources

image::pylogo.svg[CPython Logo, width=120, align="center"]

The **CPython Script Executor** transform allows you to run native Python scripts directly within an Apache Hop pipeline using CPython. It enables seamless data interchange between Apache Hop rows and Python environments (e.g., NumPy, Pandas).

== Description

Use this transform to perform custom scripting, data science transformations, machine learning inference, or advanced data manipulation using standard Python packages.

== Options

[cols="1,3", options="header"]
|===
| Option | Description

| Transform name
| Name of this transform in the pipeline layout.

2+^| Configure

| Number of Rows to Process
a|Specifies how incoming rows are grouped before being sent to Python:

* `All`: Buffers the entire input stream in memory and runs the Python script once after all rows have arrived. Ideal for global aggregations, full dataset transformations, or model training.
* `Batch`: Accumulates rows in chunks and executes the script repeatedly for each chunk. **Unlocks the _Batch size_ field.** Ideal for processing large datasets without exhausting memory.
* `Row by Row`: Executes the Python script once for every incoming row (batch size of 1). Use with caution on large datasets due to per-row execution overhead.

|Batch size
|*(Enabled only when `Rows to process` is set to `Batch`)* +
The number of rows to accumulate before executing the Python script (e.g., `10000`). Supports Hop variables (e.g., `${BATCH_SIZE}`).

| Reservoir sampling
|When checked, activates the streaming reservoir sampling algorithm to select an unbiased, statistically uniform random sample of rows from the incoming stream. **Unlocks the _Reservoir sampling size_ and _Random seed_ fields.** Prevents out-of-memory errors on massive datasets while maintaining representative distributions for ML model training and plotting.

|Reservoir sampling size
|*(Enabled only when `Reservoir sampling` is checked)* +
The maximum number of rows ($k$) to keep in the final random sample (e.g., `50000`). Once the stream finishes, only these sampled rows are sent into the DataFrame. Supports Hop variables (e.g., `${SAMPLE_SIZE}`).

|Random seed
|*(Enabled only when `Reservoir sampling` is checked)* +
An optional integer used to initialize the pseudo-random number generator. Setting a fixed seed guarantees identical, deterministic row selection across repeated pipeline executions. If left blank or set to `0`, sampling is non-deterministic (seeded by system time). Supports Hop variables (e.g., `${SAMPLING_SEED}`).

|Include Input Fields as Output Fields
|When checked, incoming stream fields are preserved and merged into the outgoing row alongside the columns/variables produced by the Python script. If unchecked, only the fields generated by the Python script are passed downstream.

|Python configuration
|Selects a reusable **CPython Config** metadata object defining the Python executable (`pythonCommand`), additional `sys.path` directories (`pyPathEntries`), and daemon process identifier (`serverID`). If left blank, the transform automatically falls back to your active virtual environment (`$VIRTUAL_ENV`), the `HOP_CPYTHON_COMMAND` variable, or the system default `python3`/`python`.

|Python libraries
|A space-separated list of Python packages required by your script (e.g., `scikit-learn seaborn scipy`). Before launching the Python daemon, the transform inspects the target environment and automatically runs `pip install` for any missing libraries.

|PyArrow
|When enabled, uses Apache Arrow IPC binary streaming to transfer DataFrames between the Hop JVM and Python over the socket. This offers high-throughput, near zero-copy serialization. If unchecked—or if the `pyarrow` package is missing in the target Python environment—the transform falls back to CSV text streaming.

|Input frames
a|A table mapping incoming Hop data streams to Pandas DataFrame variable names in your script. Each connected upstream transform must have a row defined here:

* **Transform name**: The connected upstream transform providing incoming rows.
* **Frame name**: The Python variable name under which the rows will be accessible as a `pandas.DataFrame` (e.g., `df`, `orders`, `transactions`). Must be a valid Python identifier. Supports Hop variables.

== Data Passing & Context

* **Input Data:** Hop rows are exposed to CPython as native data structures or a Pandas DataFrame.
* **Output Data:** Fields generated or modified in Python can be extracted back into the Hop pipeline stream.

== Usage Notes

1. Ensure standard CPython runtime and dependencies are accessible in the execution environment where Hop is running.
2. For large datasets, process data in chunks or leverage DataFrame operations to optimize performance.
